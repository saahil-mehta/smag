Overview - Circular Universal Chuck

One circular chuck for mixed work

Radial poles run from the centre to the edge, so a part is held across several poles wherever it sits on the face. Small, thin, large and thick parts are all held well.

A light hold position lets the operator set the part before the full hold. Used on lathes, rotary grinders and inspection tables. Made up to 600 mm diameter, with electromagnetic versions to order.
