One prompt per gap. Paste each into Gemini as-is. After generating, drop the
files into `assets/source/brochure-stills/` with the suggested filename and
re-run `tools/rebuild/build_smag_product_pages.py` (or ask for them to be
wired in); the build pipeline resizes them and adds the S-MAG watermark, so
the generated image must NOT contain any text, logo or watermark.

high detail, realistic fabrication detail such as weld seams and machining
marks, 4:3 landscape, no text, no labels, no logos, no watermark, no people,
no props."
